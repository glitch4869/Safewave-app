# SafeWave 보호자 앱 (안드로이드)

어르신과 보호자가 보기 쉽게 만든 낙상 감지 보호자 앱입니다.
관제 사이트(SafeWave AI Monitor)와 **같은 Firebase 계정·데이터**를 씁니다.

## 할 수 있는 것
- 관제 사이트와 같은 이메일 계정으로 로그인 (새 계정은 관리자 승인 후 사용)
- 실시간 상태를 큰 글씨와 색으로 표시: 안전해요 / 집에 안 계세요 / 넘어진 것 같아요 / 긴급
- 긴급이면 앱을 꺼 두었거나 화면이 잠겨 있어도 경보 화면, 경보음, 진동, 음성 안내
- "확인했어요" 버튼 → 관제 사이트의 보호자 확인과 똑같이 센서에 ACK 전송, 공유 기록에 남김
- 보호자 전화, 119 전화 (누르면 전화 화면이 열림)
- 레이더 이벤트와 공유 기록 보기, 어르신 정보 보기
- 글자 크기 3단계, 음성 안내 켜기/끄기, 경보 시험

## 사이트와 같이 쓰는 데이터 (safewave/<키>/...)
| 경로 | 용도 |
|---|---|
| `nodes/daegu-102-1` | 센서 실시간 상태 (실시간 스트림으로 받음) |
| `cmd/daegu-102-1` | "ACK" 보내기 (알람 확인) |
| `shared/daegu-102-1` | 대상자 정보·연락처 (관리자가 사이트에서 수정) |
| `events`, `logs/daegu-102-1` | 기록 |
| `users/<uid>` | 계정 권한 (admin / member / pending) |

## 빌드
`main` 브랜치에 올리면 GitHub Actions 가 APK 를 만들어
Releases 의 **apk-latest** 에 `SafeWave-Guardian.apk` 로 올립니다.

안드로이드 스튜디오에서 열 때는 `android` 폴더를 열면 됩니다 (Gradle 8.7 이상).

## 참고
- 서명 키 `app/safewave-capstone.jks` (비밀번호 safewave) 는 캡스톤 시연용입니다. 공개 저장소에 있으니 실제 배포에는 새 키를 쓰세요.
- 앱을 꺼도 경보를 받기 위해 "SafeWave 지키는 중" 알림이 항상 떠 있습니다.
